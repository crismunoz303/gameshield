# CODM Rank Tracker v0.1.1

Standalone SwiftUI app built on the isolated `codm-rank-tracker` branch of GameShield. This does **not** replace the GameShield app or its main branch.

## Features
- Opt-in, read-only UID lookup on app start, foreground entry, and manual refresh.
- Live Multiplayer nickname, level, rank, and Ranked XP.
- Legendary progress using 8,001 XP as the currently configured threshold.
- Local changed-reading history and XP chart, without screenshot imports.
- Clear unavailable/error state, no passwords, game patching, or background polling.

## Important limitations
- The provider `callofdutymobile.vercel.app` is **unofficial** and uses reverse-engineered access. Activision restricts unauthorized information collection. Its legality and long-term reliability are unverified.
- An XP change between readings can reflect multiple matches and does **not** prove match-specific XP, a win, or a loss.
- The UID and stats history are stored on your phone; lookup sends UID/IP to the third-party service. No account login credentials are requested.
- The **unsigned IPA** generated by GitHub Actions must be signed before installation on an ordinary iPhone. It is not an already-installed or pre-signed app.

## Build verification
See GitHub Actions workflow **CODM Rank Tracker - unsigned IPA**. It runs `xcodegen`, compiles the application with Apple's iOS SDK, tests IPA ZIP integrity, and uploads an artifact. A passing workflow verifies compilation/package integrity, **not** device installation or third-party provider authorization.

## Build on Mac
Install Xcode and `xcodegen`. In this folder run:
```sh
xcodegen generate
xcodebuild -project CODMRank.xcodeproj -scheme CODMRank -configuration Release -sdk iphoneos -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build
```
